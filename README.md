# Welcome to my personal Archipelago Manual for Advance Wars 2 (GBA): Black Hole Rising's normal campaign
This repository is just to include my apworld and yaml
This currently only supports the base campaign with artificial walls based around factors
1. Progressive Regions (Each ongoing one allows you to progress through the story, with Blue Moon expected before Yellow Comet before Green Earth into finally Black Hole)
2. Factory, Port and Airport Upgrades. Without you are not expected to use any tier 2 or 3 units  
a) Mechs count on the same tier as Infantry, but Md Tanks/Rockets/Missiles are considered an upgrade requirement  
NB - Neotanks requires two upgrades but per region also require the Proof of Neotanks to be purchased  
b) Battleships, Cruisers and Submarines are considered tier two for docks  
c) Bombers and Fighters are considered tier two for airports.  
4. If there becomes a need to add a Hard Campaign I can try to logically figure out the requirements later on.
